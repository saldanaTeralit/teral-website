2. Instrucciones de Instalación

Sigue estos pasos detallados para completar de forma satisfactoria la implementación local de la aplicación en las terminales comerciales:

1
Descarga e Inicia
Descarga el archivo .exe del panel superior. Haz clic secundario sobre él y selecciona Ejecutar como Administrador.
2
Configuración Ruta
Elige la ruta de instalación por defecto. Generalmente instalada en C:\Teral\CotizadorMicrosip\ para evitar restricciones de permisos UAC de Windows.
3
Cadena Conexión
Al abrir la aplicación por primera vez, ingresa en el menú Ajustes > Conexión e introduce los datos del host de Firebird y la ruta de la base de datos del ERP.
4
Validación Final
Realiza una prueba de login con un usuario registrado en el sistema. Asegúrate de verificar la lectura correcta del catálogo de clientes e inventarios.

3. Características Técnicas Destacadas

El sistema cuenta con un abanico de módulos y flujos robustos creados expresamente para optimizar el rendimiento comercial diario.

Sincronización en Tiempo Real

Lee de forma directa las tablas del diccionario de datos de Microsip (Artículos, Existencias por Almacén, Clientes, Reglas de Descuento y Monedas) sin esperas de sincronización ni bases de datos intermedias propensas a desincronizarse.

Generación Dinámica de PDFs

Incluye un motor local de reportes para crear cotizaciones en PDF con el branding exacto, notas comerciales, márgenes definidos y desgloses de impuestos listos para enviar al cliente final en un solo clic.

Integración Transaccional Escrita

Inserta las cotizaciones de venta directamente en la base de datos de Microsip respetando las llaves foráneas, tablas de encabezado de ventas y tablas de detalle (DOCTOS_VE, DOCTOS_VE_DET) bajo transacciones atómicas de Firebird.

4. Detalles de Arquitectura e Integración

Esta sección expone los detalles internos del flujo y arquitectura del sistema para facilitar el mantenimiento y control técnico en el futuro.

Esquema de Integración y Conexión

El cotizador se conecta al ERP utilizando el protocolo local o de red de Firebird SQL. La autenticación de la base de datos requiere de un usuario con permisos de lectura y escritura en los esquemas comerciales de Microsip.

# Ejemplo de Cadena de Conexión en Configuración Interna Server=192.168.1.150;Port=3050;Database=C:\Microsip Datos\TERAL_SOLUTIONS.FDB;User=SYSDBA;Password=masterkey;Dialect=3;Charset=NONE;

Nota de seguridad: Se recomienda aislar el acceso a la base de datos creando un usuario Firebird restringido en lugar del usuario administrador por defecto SYSDBA.
